mail-reader — Privacy Policy

Last updated: October 8, 2026

Who uses this app

mail-reader is a personal tool used only by its developer to access the developer's own Google accounts. It is not offered to the public.

What data is accessed

With the Gmail API scope gmail.readonly, the app reads email metadata (sender, subject, date) and message text of selected emails. It cannot send, delete, label or otherwise modify emails.

How data is used and stored

  • Emails are read only to create a private summary for the account owner.
  • To write that summary, the text of selected emails is processed by an AI model (Anthropic Claude) on the owner's behalf.
  • Authorization tokens are stored locally in the owner's macOS Keychain.
  • Summaries are stored locally on the owner's computer.
  • Data is not sold, shared with third parties or used for advertising.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
